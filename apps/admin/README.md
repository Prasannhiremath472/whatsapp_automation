# Genie Admin Panel — React

Converted from the Lovable/TanStack Start project to a standard React + TypeScript + Vite single-page application.

## Stack
- React 19 + TypeScript
- Vite
- React Router
- Tailwind CSS v4
- TanStack Query
- Radix UI / shadcn-style components
- Recharts and Lucide icons

## Run locally

Use Node.js 20.19+ (or a current compatible LTS release).

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Included screens

- Sign in, forgot password, reset password and access denied
- Super Admin dashboard
- Business onboarding and business management
- AI tokens, providers and usage
- Plans, payments and revenue analytics
- Support tickets, requests and client success
- Admin users, roles, account settings and global settings
- Integrations, WhatsApp management and automations
- Notifications, audit logs, activity logs, error logs and system monitoring
- Platform, business and usage analytics

## Demo behavior

This is a frontend demo. The included admin store and session utilities use browser-side demo data. Role switching and sign-in are simulated in the browser; they are not production authentication or server-side authorization. Connect a secured backend before using it with real business or customer data.
