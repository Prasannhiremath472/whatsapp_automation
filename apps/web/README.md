# Genie — WhatsApp Business Automation (React)

Converted from the Lovable/TanStack Start project to a standard React + TypeScript + Vite single-page application.

## Stack
- React 19 + TypeScript
- Vite
- React Router
- Tailwind CSS v4
- TanStack Query
- Radix UI / shadcn-style components
- Recharts and XYFlow

## Run locally
Install Node.js 20.19+ (or a compatible current LTS), then run:

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run preview
```

## Pages
Dashboard, Team Inbox, Contacts, Campaigns, Message Templates, Automations, AI Agents, Analytics, WhatsApp Accounts, Teams, Integrations, Developer Console, API Keys, Webhooks, API Logs, API Documentation, Help, Settings and Profile.

## Demo data
This project currently uses the included local demo provider and sample data. It is a frontend demonstration, not a live WhatsApp Business API integration.
